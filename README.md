# AUTONOMIA — Build Calc Kit Express MZ

Página de apresentação para GitHub Pages. Apenas demonstração e pedido de compra por e-mail; não existe checkout ligado, nem entrega automática.

Para publicar, em Settings → Pages selecciona Deploy from a branch, branch gh-pages, /(root). Aguarda confirmação da URL fornecida pelo GitHub.

IMPORTANTE: não adicionar o ficheiro XLSX completo a este repositório público. Após activar um processador de pagamentos autorizado, substituir o pedido por e-mail por checkout seguro com entrega protegida. Nunca inserir chaves privadas ou palavras-passe neste site estático.
